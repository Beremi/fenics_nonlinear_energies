Second, the fixed-reference PMG profile is not the default used in the
present study: it may appear favorable on completed low-rank configurations, but
it reaches the maximum number of Newton iterations on more of the reported rank
counts and therefore gives less consistent convergence evidence. The rank-local
constitutive-AD path remains the primary Plasticity3D realization because it uses the
same local differentiable formulation as the derivative-route and converged
scaling studies; the reference-formula configurations are retained to expose
solver-policy sensitivity on matched discrete problems.
