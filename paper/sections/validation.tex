\label{sec:validation}

Validation evidence is scoped separately from performance results because the
comparisons have different roles. Hyperelasticity has a narrow endpoint-state
comparison against JAX-FEM, while \plasticitythree{} is evaluated through an
endpoint-surrogate comparison defined by \Cref{sec:bench-plasticity3d}.

\subsection{Comparison Metrics}
\label{sec:val-metrics}

For vector and field comparisons with nonzero reference norm, we report
relative differences of the form
\begin{equation}
  \delta_M(a,b)
  =
  \frac{\|a-b\|_M}
       {\|a\|_M},
  \label{eq:validation-relative-difference}
\end{equation}
where $a$ is the reference observable, $b$ is the compared observable, and $M$
denotes the discrete norm used for the comparison. For nodal displacement
vectors, $M$ is the identity on the compared free degrees of freedom. For scalar
field samples $r_q$, we use $\|r\|_M^2=\sum_q w_q r_q^2$. For vector-valued
samples $r_q\in\mathbb{R}^m$, we use
$\|r\|_M^2=\sum_q w_q r_q^\top G r_q$, where $G$ is stated with the observable.
The reported 3D plasticity deviatoric-strain observable is the scalar field
$\|\varepsilon_{\mathrm{dev}}\|$ from \eqref{eq:plasticity3d-devnorm}. Curve
metrics are specified separately below. The reported field and profile
observables have nonzero reference norms. For scalar observables, including
signed energy and work, we use $|a-b|/|a|$. For the hyperelastic endpoint
energy, the denominator is $\max\{|a|,\num{1e-12}\}$. We write $u_{\max}$ for
the maximum displacement magnitude over the compared state.

Curve metrics use unweighted Euclidean norms on ordered reference samples. For
the hyperelastic companion, the centerline sample set is
$C_{\mathrm{HE}}=\{i:\ y_i=z_i=0\}$ in the reference coordinates
$X_i=(x_i,y_i,z_i)$, ordered by $x_i$, and the compared observable is $u_x$ on
that set. The hyperelastic $u_{\max}$ curve uses the four prescribed
right-face displacement steps as its ordered samples, and the
\plasticitythree{} $u_{\max}(\lambda_{\mathrm{sr}})$ curve uses the tested
strength-reduction grid; both use the same reference-denominator Euclidean norm
as \eqref{eq:validation-relative-difference}. For \plasticitythree{}, let
$y_{\mathrm{mid}}=(\min_i y_i+\max_i y_i)/2$, let
$L_y=\max_i y_i-\min_i y_i$, and let $q_{0.6}(z)$ be the 0.6 quantile of the
reference $z$ coordinates. The upper-slope profile sample set is
$C_{\mathrm{P3D}}=\{i:\ |y_i-y_{\mathrm{mid}}|\le 0.04 L_y,\;
z_i\ge q_{0.6}(z)\}$, ordered by $x_i$, and the compared observable is the
displacement magnitude. The candidate upper-slope profile is linearly interpolated
to the reference $x_i$ coordinates before computing \eqref{eq:validation-relative-difference}.

The hyperelastic JAX-FEM comparison uses a fixed 5\% engineering gate for the
final energy, Euclidean nodal full-field displacement, centerline displacement, and
$u_{\max}$-curve differences. The \plasticitythree{} fixed-$\lambda_{\mathrm{sr}}$
endpoint-formula diagnostic uses three fixed criteria: at most $0.03$ relative
difference in the highest successful strength-reduction factor, at most
$0.05$ relative Euclidean difference on the ordered
$u_{\max}(\lambda_{\mathrm{sr}})$ samples, and at most $0.10$ relative
discrete-norm difference for the endpoint displacement. The deviatoric-strain
and upper-slope profile differences in \Cref{tab:plasticity3d-validation} are
diagnostics, not acceptance criteria.
These thresholds are fixed engineering agreement gates for companion and
surrogate comparisons. They are not literature validation tolerances and do not
replace path-history validation for elastoplastic evolution.

\subsection{Hyperelasticity External Comparison}
\label{sec:val-hyperelasticity}

The hyperelasticity energy is defined in \Cref{sec:bench-he}. The external
comparison uses JAX-FEM \citep{xue2023jaxfem} in a deliberately narrow serial
companion case rather than the 24-step rotating benchmark path. Both
implementations use the same level-1 mesh and the same right-face
$x$-translation schedule
$d=(0.0025,0.005,0.0075,0.01)$. Both endpoint states are evaluated with the
common energy functional \eqref{eq:hyperelasticity-energy}. This supports
endpoint-state observable agreement for this hyperelastic companion problem
only. The comparison is therefore a common-energy endpoint-state check for one
hyperelastic case, and it does not assert constitutive-law identity between the two
implementations: the specific JAX-FEM companion case used here uses a
logarithmic-$J$ Piola form, whereas \eqref{eq:hyperelasticity-energy} uses the
$D_1(J-1)^2$ volumetric penalty.

\subsection{3D Mohr--Coulomb Endpoint-Surrogate Comparison}
\label{sec:val-plasticity3d}

The \plasticitythree{} benchmark is tied to Mohr--Coulomb slope-stability
reference formulations, but the object studied here is the algorithmic
endpoint surrogate defined in
\Cref{sec:bench-plasticity3d} by
\eqref{eq:plasticity3d-discrete} and \eqref{eq:plasticity3d-potential}.
The Sysala return-mapping, optimization, convex-optimization, and advanced
continuation papers provide reference-model and method context for this problem
class
\citep{sysala2017returnmapping,sysala2021optimization,sysala2025convexoptimization,sysala2025advancedcontinuation}.
The efficient \v{C}erm{\'a}k--Sysala--Valdman MATLAB elastoplastic
implementation of \citet{cermak2019efficient} provides implementation context
for practical two- and three-dimensional elastoplastic finite-element solvers.
None of these sources is
used here as a verified numerical baseline.

The endpoint-surrogate comparison therefore uses two diagnostics. First, an
independent endpoint-formula assembly evaluates the same endpoint surrogate, not
the cited incremental-history studies. It uses the same endpoint functional,
mesh, material table, Davis-B strength-reduction schedule, and
boundary-condition convention, but computes the endpoint observables through
the separate assembly.
The endpoint-observable check tests a seven-step strength-reduction sequence,
$\lambda_{\mathrm{sr}}=\num{1.0},\num{1.1},\ldots,\num{1.6}$, against this
independent endpoint-formula assembly on the $P_2(L_1)$ endpoint-surrogate
configuration.
The work observable is the external work $\omega=f_{\mathrm{ext}}^\top x_h$,
where $x_h$ is the free coefficient vector of the endpoint displacement $u_h$,
reported by the two endpoint formulations. Its relative difference is
\num{3.877e-5}, the displacement relative discrete-norm difference is
\num{3.517e-3}, and the deviatoric-strain relative discrete-norm difference is
\num{8.720e-3}.

The fixed-$\lambda_{\mathrm{sr}}$ endpoint-formula diagnostic compares the same
two endpoint formulations using common bottom-clamped boundary conditions and
the same active free-DOF set. The fixed-$\lambda_{\mathrm{sr}}$ grid is capped
at the main-figure strength-reduction value
$\lambda_{\mathrm{sr}}=\num{1.55}$. Here
$\lambda_{\max}^{\mathrm{succ}}$ denotes the largest value in the tested grid
$\{\num{1.0},\num{1.2},\num{1.4},\num{1.5},\num{1.55}\}$ that satisfies the relative-correction stopping
criterion. The comparison matches $\lambda_{\max}^{\mathrm{succ}}$ on that grid
and satisfies the fixed engineering criteria for the
$u_{\max}(\lambda_{\mathrm{sr}})$ curve and endpoint displacement: the
$u_{\max}(\lambda_{\mathrm{sr}})$ relative Euclidean difference is
\num{6.396e-6}, and the endpoint displacement relative discrete-norm difference
is \num{8.299e-4}. The endpoint deviatoric-strain relative discrete-norm
difference (\num{4.307e-3}) and upper-slope profile relative Euclidean difference
(\num{5.229e-4}) are reported as diagnostics rather than acceptance criteria.
This remains an endpoint check rather than a path-consistent plastic-history
reference.
