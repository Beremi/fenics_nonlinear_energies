\label{sec:validation}

Verification proceeds from independent mathematical checks to route and MPI
comparisons. Each block names the object being compared and the norm used for
its gate. None of the tests below is interpreted as timing evidence.

\subsection{Normalization and admission gates}
\label{subsec:verification-normalization}

For two scalars, vectors, or matrices of the same physical type, route and
analytic defects use
\begin{equation}
  \delta(a,b):=
  \begin{cases}
    0, & \lVert a\rVert=\lVert b\rVert=0,\\
    \displaystyle\frac{\lVert a-b\rVert}
      {\max(\lVert a\rVert,\lVert b\rVert)}, & \text{otherwise},
  \end{cases}
  \qquad
  \delta_{\mathrm{sym}}(A):=
  \begin{cases}
    0, & \lVert A\rVert_{\mathrm F}=0,\\
    \displaystyle\frac{\lVert A-A^\top\rVert_{\mathrm F}}
      {\lVert A\rVert_{\mathrm F}}, & \text{otherwise}.
  \end{cases}
  \label{eq:verification-relative-defects}
\end{equation}
Here $\lVert\cdot\rVert$ denotes absolute value for scalars, the Euclidean norm
for vectors, and the Frobenius norm for matrices. Every comparison involving a
zero object is also reported in absolute terms.
The distribution diagnostic instead uses the pilot-specific numerical floor
$\max(1,\lVert a\rVert,\lVert b\rVert)$ in the stored units; this arbitrary
absolute scale is one reason it is not reused as a physical endpoint norm.

Manufactured Newton solves report
$\lVert R_{h,\mathrm{free}}^{(k)}\rVert_2/
 \lVert R_{h,\mathrm{free}}^{(0)}\rVert_2$ and require it to be at most
$10^{-8}$. Spatial errors are quadrature approximations of
$\lVert u_h-u_\star\rVert_{L^2}$ and
$\lVert\nabla u_h-\nabla u_\star\rVert_{L^2}$; the mechanics block additionally
uses $\lVert P_h-P_\star\rVert_{L^2}$.

For a unit direction $d$, the centered action check is
\begin{equation}
  D_hg(x;d):=\frac{g(x+hd)-g(x-hd)}{2h},
  \qquad \delta\bigl(D_hg(x;d),H(x)d\bigr).
  \label{eq:centered-action-check}
\end{equation}
The smooth-energy gate uses $h=3\times10^{-5}$; the fixed-element plasticity
gate uses $h=10^{-7}$; and the material-point gate uses $h=10^{-6}$. The
corresponding action tolerance is $10^{-7}$, route defects must not exceed
$10^{-8}$, and smooth-branch symmetry defects must not exceed $10^{-10}$.
Complete step sweeps are retained rather than fitting the roundoff tail.

For the branch diagnostic, every predicate is divided by a scale of the same
units: yield predicates use the maximum of the cohesion, trial value, and
elastic stress terms, while multiplier/interface predicates use the maximum
of the principal strains, return multipliers, return tests, and
$\bar c_\lambda/\max(|\mu|,|K|,|\lambda_{\mathrm L}|)$. The active margin is
the minimum signed normalized inequality required by the selected first-match
row. Strict interiors require a margin of at least $10^{-3}$; the separate
quadrature exclusion band is $10^{-8}$.

\subsection{Hyperelastic verification}
\label{sec:val-hyperelasticity}

On the affine patch, the relative energy, residual, and Hessian discrepancies
are $4.58\times10^{-15}$, $2.67\times10^{-15}$, and
$4.38\times10^{-16}$. Boundary-traction balance is
$1.75\times10^{-16}$ relatively. The net internal-force norm is
$1.92\times10^{-16}$ and the largest rigid-translation Hessian-action norm is
$1.19\times10^{-15}$, both absolute values in the nondimensional force units
of the unit-cube test. A superposed rotation gives zero stored energy defect
and $7.94\times10^{-17}$ Piola covariance error.

The nonaffine manufactured problem uses 4, 8, 16, and 24 subdivisions per
axis. All four meshes converge in four damped Newton steps. The last-pair orders
are $1.887$ for displacement $L^2$, $1.006$ for the deformation-gradient
error, and $0.983$ for first-Piola stress. The minimum computed determinant is
$0.844$, and tangent symmetry defects remain below $8.6\times10^{-17}$.
Orders 4, 6, and 8 are compared for the analytic load. The largest induced
response change is $8.29\times10^{-6}$ of the finite-element error and the
largest load change is $1.78\times10^{-5}$ of the exact-interpolant consistency
residual; both ratios decrease under refinement.
Thus the test shows observed convergence for a nontrivial
orientation-preserving formulation, but not
the production rotating-boundary trajectory.

\subsection{Canonical distributed equivalence}
\label{subsec:distributed-verification}

The hyperelastic one- and two-rank workers reproduce the coordinates,
connectivity, boundary map, affine lift, state, direction, and CSR indices as
bitwise-identical stored arrays. The stored residual and matrix differences are
zero in FP64. Relative errors
are $8.67\times10^{-19}$ in energy, $2.24\times10^{-16}$ in the matrix action,
and $2.33\times10^{-16}$ in the MUMPS correction. Independently recomputed
linear residuals are below $1.9\times10^{-15}$. This verifies the varied rank
partition for rank-local element-Hessian assembly at one fixed state; it does
not test distributed colored recovery, nonlinear endpoints, or parallel time.

\subsection{Plasticity scope}
\label{sec:val-plasticity3d}

The Plasticity3D tests verify the scalar branch program and its derivatives,
not a distinct constitutive implementation. The NumPy material-point code
independently implements rotations, finite differences, and interface
construction, but transcribes the same endpoint energy. We therefore call the
result internal verification. Physical validation would require a matched
incremental return map and a recognized boundary-value benchmark with common
history, constraints, and material assumptions.

The same limitation applies to repeated spectra. The deterministic tie
convention prevents nonfinite AD values and provides a reproducible selected
branch. It does not make the ordinary Hessian unique at an exact eigenvalue
degeneracy.

\paragraph{Evidence status.}
The displayed values are diagnostic results of the revision implementation.
They are traceable to strict artifacts and code hashes, but must be reproduced
from the clean, immutable release commit before journal submission. No matched
DOLFINx result is used: the unavailable local binary stack is treated as a
scoped comparator omission rather than as evidence.
